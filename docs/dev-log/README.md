결과의 신뢰성과 관련된 기록:

- Qwen3 판단이 의도한 greedy 조건으로 실행되지 않던 문제를 발견해 수정했고, 그 이전의 출력은 결과에 사용하지 않았다 (decisions.md D012).
- 긴 입력의 메모리 정책을 도입한 뒤 Test의 모든 압축·판단을 처음부터 같은 정책으로 다시 생성했다 (D013·D014).
